# AI 视觉对话助手 — 会话管理说明

## 对话流程
用户每次说话会触发一轮完整的对话处理：
1. 麦克风采集音频 → VAD 检测语音活动
2. 音频发送到服务端 → 百度 STT 转为文字
3. 摄像头画面 → GLM-4V 分析画面内容
4. 语音文字 + 画面描述 → IntentRecognizer 判断意图
5. 根据意图路由到对应的 Agent 处理
6. Agent 调用 LLM 生成回复 → 推送到前端显示

## 语音识别优化建议
- 在安静环境中使用，减少背景噪音
- 距离麦克风 30-50cm，说话清晰
- 支持中英文混合识别
- 短句识别更准确（10字以内最佳）

## 画面分析优化建议
- 保持面部在画面中央
- 展示物体时靠近摄像头
- 光线充足时识别效果更好
- 衣服颜色和款式可以被识别
- 手势动作（挥手、指向）可以被捕捉

## 对话记忆
- 服务端保留最近 8 轮对话历史
- 超出部分自动压缩为摘要
- 摘要会累积，不会丢失重要上下文
- 关闭浏览器后会话结束，历史清空

## 状态指示器
- 就绪：等待语音输入
- 识别中：正在将语音转为文字
- 思考中：正在分析并生成回复
- 错误：网络或服务异常，请重试
