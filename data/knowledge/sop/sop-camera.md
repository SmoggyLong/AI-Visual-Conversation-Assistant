## 步骤1：确认浏览器权限
检查浏览器地址栏左侧的权限图标。确保摄像头权限为"允许"。如果误点了"禁止"，需要点击图标手动修改。

## 步骤2：检查设备管理器（Windows）
```bash
# 打开设备管理器 → 照相机
# 确认摄像头设备已启用（无黄色感叹号）
```

如果设备被禁用，右键 → 启用设备。

## 步骤3：浏览器兼容性
- Chrome 70+ 支持 getUserMedia API
- Edge (Chromium) 完全支持
- Firefox 支持但可能有帧率差异
- Safari 需要在"偏好设置→网站→摄像头"中授权

## 步骤4：摄像头被其他应用占用
关闭以下可能占用摄像头的应用：
- 微信视频通话
- Zoom / 腾讯会议
- OBS Studio
- Windows 相机应用

## 步骤5：重启浏览器
清除缓存后重启浏览器。如果仍然不行，尝试无痕模式测试是否为插件冲突。

## 常见错误码
- `NotFoundError`: 未检测到摄像头硬件
- `NotAllowedError`: 用户拒绝了权限
- `NotReadableError`: 摄像头已被其他应用占用
- `OverconstrainedError`: 请求的分辨率不支持
