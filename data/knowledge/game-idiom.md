## 基本规则
1. AI先出或用户先出一个四字成语
2. 下一个人接的成语首字读音必须与上一个人成语尾字读音相同
   - 例如：一心一意 → 意味深长 → 长驱直入
   - 同音即可，不要求字形相同（如"长"接"常"也可以）
3. 不能重复已经用过的成语
4. 接不上就说"我接不上了，你赢了"

## 接龙技巧
- 记住常用尾字接法：意→义/异/议/谊、长→常/尝/场/厂
- 尾字"了"、"的"、"子"等虚字开头的成语较少，可以提前准备
- 如果对方用了罕见尾字，可以用同音字替代

## 常见成语链示例
- 一心一意 → 意气风发 → 发人深省 → 省吃俭用 → 用心良苦 → 苦口婆心 → 心灵手巧 → 巧夺天工 → 工力悉敌
- 龙飞凤舞 → 舞文弄墨 → 墨守成规 → 规行矩步 → 步步为营 → 营私舞弊 → 弊绝风清 → 清心寡欲

## 非成语示例（AI会拒绝）
- 武动乾坤（小说武功名，非成语）
- 乾坤大挪移（五字，非成语）
- 好好学习（口语，非成语）
