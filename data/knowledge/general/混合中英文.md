## Step 1: Check Application Log
Run the following command to view the latest ERROR logs:

```bash
docker logs -f backend 2>&1 | grep ERROR
```

## Step 2: Common NPE Patterns
```java
// Bad: potential NPE
String name = user.getProfile().getName();

// Good: use Optional
String name = Optional.ofNullable(user.getProfile())
    .map(Profile::getName).orElse("unknown");
```

## 步骤3：检查数据库连接
使用 DBeaver 连接 MongoDB `mongodb://localhost:27017/avca`，确认集合 avca_knowledge 存在。

> **注意**：生产环境不要直接连接数据库，使用只读账号。
